<h3 id="🔑-jwt-인증-방식-개선">🔑 JWT 인증 방식 개선</h3>
<p>httpOnly Cookie 기반 JWT 인증으로 수정</p>
<pre><code class="language-python">response.set_cookie(
    key='access_token',
    value=str(access_token),
    max_age=3600,
    httponly=True,      # JavaScript 접근 차단
    secure=use_secure,  # HTTPS에서만 전송
    samesite='Lax',     # CSRF 방어
    path='/',
)</code></pre>
<p>요청 시 쿠키 자동 전송되게 프론트단도 수정</p>
<pre><code class="language-javascript">const response = await fetch(url, {
  credentials: 'include',  // 쿠키 자동 포함
});
</code></pre>
<p>이제 JavaScript에서는 토큰에 접근할 수 없고 브라우저가 알아서 쿠키를 주고 받게 된다!
개발자도구를 열어봐도 토큰 값XXXX</p>
<h2 id="🔥-postgresql-인증-오류">🔥 PostgreSQL 인증 오류</h2>
<pre><code>FATAL: Ident authentication failed for user &quot;postgres&quot;
</code></pre><p>PostgreSQL 기본 인증 방식이 ident로 되어있는데 내 시스템 계정과 PostgreSQL 계정이 일치하지 않아 접속을 허용이 안되는 거였다</p>
<p>pg_hba.conf에서 인증 방식 변경해서 해결함</p>
<pre><code class="language-bash"># /var/lib/pgsql/data/pg_hba.conf
local   all   all   md5
host    all   all   127.0.0.1/32   md5
</code></pre>
<p>배포하면서도 더 많은 오류들을 마주쳤었는데
추후에 트러블슈팅 글로 다시 찾아오겠다
오늘은 회고 글이니까</p>
